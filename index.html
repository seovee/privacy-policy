내쓸모 개인정보 처리방침

시행일: 2026년 4월 12일

1. 수집하는 개인정보

내쓸모는 어떠한 개인정보도 수집하지 않습니다.

모든 데이터(할 일, 메모, 완료 기록)는 사용자의 기기에만 저장되며, 외부 서버로 전송되지 않습니다.

2. 데이터 저장

앱에서 생성한 모든 데이터는 기기 내부 저장소(SwiftData)에 로컬로 저장됩니다. 인터넷 연결 없이도 앱의 모든 기능을 사용할 수 있습니다.

3. 제3자 공유

사용자 데이터를 제3자와 공유하지 않습니다. 광고 SDK, 분석 도구, 추적 도구를 사용하지 않습니다.

4. 데이터 삭제

앱을 삭제하면 모든 데이터가 기기에서 완전히 삭제됩니다.

5. 아동 개인정보

본 앱은 아동의 개인정보를 수집하지 않습니다.

6. 변경사항

본 방침이 변경될 경우 앱 업데이트를 통해 안내합니다.
